qurl.sh

Fast, terminal friendly ephemeral file sharing.

The fastest way to pipe files to the web.

Upload

Upload a file from your terminal.

$ curl -T file.txt https://qurl.sh

With Password:

$ curl -T file.txt -H "X-Password: 123" https://qurl.sh

TTL & Limits: (Max 7d and 100 downloads)

$ curl -T file.txt -H "X-TTL: 1h" https://qurl.sh
$ curl -T file.txt -H "X-Downloads: 5" https://qurl.sh

Download

Get your file back with a simple command.

$ wget https://qurl.sh/abcd/file.txt
$ curl -O https://qurl.sh/abcd/file.txt

Send to Phone

Stuck in an SSH session with a file you need on your phone? No cable, no account, no AirDrop.

1. Upload it — the reply hands you a QR link: 

$ curl -T file.txt https://qurl.sh
✔ Success - uploaded file.txt (12 KB)
...
QR Code: https://qurl.sh/qr/abcd/file.txt

2. Fetch that link to draw the code in your terminal:

$ curl https://qurl.sh/qr/abcd/file.txt

Point your phone camera at it and the download starts. Open the same URL in a browser for a PNG instead — handy when screen-sharing.

Pretty Print

Visualize JSON, YAML, or XML.

$ curl -F "file=@c.yaml" https://qurl.sh/pretty

Encrypted Secrets

Share text securely (AES-128).

$ echo "secret" | curl -d @- https://qurl.sh/secret

Code Viewer

View code with syntax highlighting.

Just open the file link in your browser.

Defaults: files a browser can show — text, code, images, PDFs — last 7 days or 100 downloads. Archives and binaries are deleted after 1 download or 24 hours. Override either with X-TTL or X-Downloads. Max {{ max_size_mb }} MB.

No signup, no API key, nothing to install. Read the full documentation — or curl https://qurl.sh for help in your shell.
